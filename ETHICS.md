# Ethics and Governance Boundary

This repository is an evaluation study, not a deployment recommendation.

Student-risk predictions can create harm through false positives, false negatives, stigmatization, surveillance, differential access to support, self-fulfilling feedback loops and opaque escalation. Historical labels can also encode institutional and structural inequities.

## Safeguards in the empirical study

- enrollment-time feature boundary;
- post-enrollment semester-performance variables excluded;
- gender and nationality excluded from prediction;
- group metrics reported separately rather than collapsed into one fairness score;
- probability calibration evaluated alongside classification metrics;
- threshold sensitivity reported;
- small-group safeguards in the evaluation toolkit;
- bootstrap uncertainty for selected metrics;
- explicit non-claims about fairness, legality and beneficial intervention.

No single parity metric defines fairness. Any consequential use would require stakeholder review, privacy and accessibility review, human oversight, appeal pathways, prospective impact evaluation and institution-specific validation.
